# Natural Pixels

Original deterministic pixel artwork by the MinecraftC project, 2026-10-25.
Textures and authoring palettes are released under CC0-1.0.
No Mojang/Minecraft images or third-party texture packs are included.
The visual brief references only general modern voxel pixel-art conventions.

Reproduce with `python3 tools/natural_pixels.py` from the repository root.
Shared drawing, semantic maps and PNG encoding helpers: MinecraftC tools/texture_generator.py
and tools/texture_recipes.py. Code follows the repository GPL-3.0-only license.
