# Claude Code Instructions

Before working in this repository, read:

1. `AGENTS.md` — project overview, architecture, development commands, and
   long-term working rules.
2. `PLAN.md` — the current task scope, technical decisions, stages, risks, and
   completion criteria.
3. `PROGRESS.md` — verified implementation state, validation results, known
   issues, migration record, and recovery steps.

These files are the current project facts and task-state sources. Verify them
against the code, Git worktree, and fresh test output before resuming work.

This file intentionally contains no additional Claude-specific rules.
