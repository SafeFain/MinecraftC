# Gameplay capability data example

Copy this directory into the user-data `mods/` directory, enable `capability_demo`
in the plugin menu and restart. Create a fresh world and use `/dimension capability_demo:islands` with cheats enabled,
or use the travel charm, to inspect deterministic cross-chunk bridges and loot. In Creative, select
the example vine/resource/staff items; use the staff on a safe top surface for blink,
and test harvest/reset, climbing and the dimension environment. See
[the SDK capability guide](../../../docs/plugin-capabilities.md) for contracts.

`staff.glb` is an original untextured octahedral staff model generated for this example.
`chime.wav` is an original one-second 440 Hz sine tone with an envelope, 48 kHz mono PCM16.
Both assets and the example source are distributed under this repository's GPL-3.0-only
license; no external art, recordings or third-party assets were used.
