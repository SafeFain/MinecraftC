# Kiln Recipe Demo

Publish this directory with the content package tool, copy the result into
`mods/recipe_demo`, enable it and restart. In Survival, use the recipe book or
place one flint and either granite or diorite in the crafting grid to make a
Kiln Blank. Burn the blank in the furnace for 100 ticks and take the Kiln Tile
to collect one experience point. Use a disposable world for the demo.

The [native example](../recipe_native/README.md) declares the same recipes from C.
