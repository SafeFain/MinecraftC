# Entity Demo

Build with `cmake -S . -B /tmp/entity_demo` and `cmake --build /tmp/entity_demo`.
Copy the module and all non-source package files here into `<user-data>/mods/entity_demo/`.
See [the plugin SDK documentation](../../../docs/plugins.md) for extension contracts.

The example registers a circling mob with persistent JSON, a custom spawn egg
and an explicit builtin pig health override. Original project code under the project license.
